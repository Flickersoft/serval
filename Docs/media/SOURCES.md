# Screenshot footage sources

The screenshots in this directory show the Serval UI displaying public-domain / CC0 footage from
Wikimedia Commons, replayed through file-source cameras (see
[testing.md — A camera with no camera](../testing.md#a-camera-with-no-camera)). No clip is
redistributed here — the images are of the application itself; the procedure to regenerate them
is in [browser-testing.md](../browser-testing.md#producing-the-readme-screenshots).
